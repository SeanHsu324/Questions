# 工業電子丙級／數位電子乙級刷題網

這是純 HTML、CSS、JavaScript 靜態網站，沿用原有刷題介面與色彩主題，支援手機版與夜間模式。

## 功能

- **級別選擇**：丙級工業電子、乙級數位電子（11700）；選擇會記存在瀏覽器 `localStorage`。
- **共同科目**：工作倫理、節能減碳、環境保護、職業安全在兩個級別都可練習。
- **乙級題庫**：載入 ZIP 內 10 個乙級工作項目；自動將題目內 `images/...` 圖片路徑轉到 `images_2/...`。
- **練習模式**：循序、隨機、模擬考，以及新增的直接閱讀模式。閱讀模式會顯示整個所選題庫的所有題目，並標示正確答案。
- **單選／複選**：題目顯示題型；單選單點作答，複選可多選。複選必須完全答對才得分，沒有部分給分。
- **丙級模擬考**：80 題、100 分鐘，含共同科目每項 4 題；丙級全為單選，每題 1.25 分。
- **乙級模擬考**：80 題、100 分鐘；單選 60 題各 1 分、複選 20 題各 2 分；共同項目各 4 題（16 題／16 分），專業題目為 44 單選＋20 複選，滿分 100 分，60 分及格。

## 重要題庫說明

雖然原網站是工業電子丙級，ZIP 裡新增的乙級題庫工作項目（如「數位邏輯設計」、「程式語言」、「微控制器系統」）對應**數位電子乙級（11700）**，因此介面依實際題目內容標示，未誤稱為工業電子乙級。

目前 ZIP 的乙級題庫有 738 題（528 單選、210 複選）。官方乙級一般試卷結構與共同科目配置已按技能檢定中心規定實作；不過 ZIP 未附數位電子乙級逐工作項目的官方抽題權重表，所以 64 題專業題目前是按單選／複選題型從所有專業題庫中隨機抽取，而不是宣稱各工作項目的官方細目權重完全一致。若要做到工作項目層級的精確配題，請補充官方權重表後再設定各題組配額。
